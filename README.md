# cpp-file-check

C++17 console tool: read a text file, check numbers, write a report.

Public sample for small C++ tasks. No customer data.

## Planned behavior

- Input: a text file with one record per line.
- Check: parse numbers, reject empty lines and bad tokens.
- Output: a short report with accepted rows, rejected rows, and the reason.

## Build

Not implemented yet. Target: CMake, C++17, MSVC or g++.
